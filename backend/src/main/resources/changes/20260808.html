Searching on specifications

Until now the only way to find a part by what it is was to type a word and hope it appeared somewhere in the text — which never worked for a number. More search options on the Parts screen now has a Specifications section: pick a field, pick a comparison, type a value. Resistance at least 1k. Supply voltage 3.3 V. Capacitance exactly 100 nF. Add as many conditions as you like and a part has to satisfy all of them.

You can write the value the way you would write it anywhere else. 100nF, 0.1uF, 1e-7 and 100n are the same search, and 4k7 works as well as 4700. The search understands what the field measures, so it does not matter which spelling the part was catalogued under.

Specifications recorded as a range are searched properly too. A part specified 2 V to 5.5 V is found by asking for a supply voltage of 3.3 V, because 3.3 falls inside its range — you do not have to know how the range was written down. A search is kept in the address bar, so it survives going into a part and back, and can be bookmarked.

Specifications read the way they are written

Values are stored in a single consistent unit behind the scenes, which is what makes the search above possible, but that is no longer what you see. An access time now reads 150 ns rather than 0.00000015, a frequency 5 MHz, a width 13.97 mm, and a temperature range -40 °C ~ 105 °C. Editing a value works the same way, so what you type back is what you saw.

This applies to every field that records what it measures, not only the handful that used to declare a unit. Fields where the unit genuinely is not known — memory sizes, case codes, part counts — are left exactly as they were, because guessing at those would do more harm than good.

Part kits: enter a whole pack of parts at once

Parts are often bought in bulk as a kit — thirty resistors that share their manufacturer, package, tolerance and power rating and differ only in resistance. Adding them meant thirty rounds of the same form. The new Part Kits screen lets you fill that form in once and list the values it varies over.

A kit template looks like the New Part form, with one addition: anywhere you would type the value that changes from part to part, type ${value} instead — in the part number, the description, a specification, even a tag. Beside it you build the list of values: type one and press Enter, or paste a whole column, one value per line. A value can be removed but not edited, and the panel shows what the first part would look like so a mistyped placeholder is obvious before you save.

Generate parts then asks how many of each value came in the pack and where they are stored, and creates the lot with their stock in one go. It tells you afterwards which parts it created and which were already in your catalogue.

Buying the same kit again is the same action: parts that already exist are found rather than duplicated, and only their stock is added — anything you have since corrected on those parts is left exactly as you wrote it.
