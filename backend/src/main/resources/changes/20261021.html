Footprints: one name per package

The package of a part used to be free text, so the same package turned up as SOT23, sot-23 and TO-236AB. Footprints now come from a list, kept per organisation, of about 250 common packages: chip sizes, SOT/SOD, SOIC/TSSOP/QFN/QFP, DIP and SIP, the TO metal cans and power packages, crystals, bridge rectifiers, axial and radial passives, trimmers and valve sockets. Each one also answers to its other names, so typing TO-236 or sot23 stores SOT-23. Case and punctuation never count.

Existing parts have been moved to these names. A DIP is the 300 mil one; the wide 600 mil 24 and 28 pin versions are DIP-24W and DIP-28W. Package texts that name no package at all, such as SMD, Through hole or the Chinese distributor labels, have been cleared, and are no longer taken over from a lookup.

The new Footprints screen, below Categories, shows the list with how many parts use each footprint. There you can add a footprint, rename one (its parts follow), give it other names, or merge two entries that are the same package. The Edit Part dialog now has a footprint field, and it and Quick Add suggest names from the list and show what a typed name will be saved as.

AI access: adding parts for a new design

An AI assistant connected through AI access (MCP) can now add a part that is not in the catalogue yet: with its manufacturer part number, manufacturer, description, category and footprint, and no stock. To pick the category it looks at where similar parts are already filed. It only uses footprints from the list, and never adds a part number that is already there. It can also put parts on the order list, for a project or on their own. It orders nothing itself. This needs the parts-edit permission.
