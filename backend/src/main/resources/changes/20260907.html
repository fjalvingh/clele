An AI assistant can now see your projects — and build their parts lists

The AI access you can set up under My Account → AI access (MCP) used to show an assistant the catalogue and nothing else. It now knows about projects too: it can list yours, and read a project's parts list line by line — what each build instance needs, how many the project is holding, and where it is running short.

It can also add a part to a project's parts list and take one off again. So "which of the diodes I already own would work here, and put four of them on the Synth voice card" is now one conversation rather than a search followed by a lot of clicking.

Which means, for the first time, an assistant can move your stock

This is worth reading twice. Putting a part on an active project's list takes it off the shelf — that is how projects have always worked, and it is just as true when the request comes from a chat window. Taking the part off the list puts everything the project was holding back where it came from.

Everything else stays read-only: nothing reached this way can create or change a part, a specification, a category or a location, and stock cannot be moved in any other way. Projects are private to their owner, so an assistant sees only your own — never a colleague's. And changing a parts list needs the same Edit parts permission you would need to do it in the browser: if you do not have it in that organisation, neither does the assistant, and it is told so plainly.

Nothing you already set up changes on its own. Existing keys and connectors keep working and simply gain the new abilities, within the permissions you already hold.
