Let an AI assistant search your parts

Sortiment can now answer questions about your own stock through an AI assistant. Ask Claude — or any other assistant that speaks the Model Context Protocol — "do I have a 100 nF 0805 in stock?", "which of my op-amps run off 3.3 V?" or "what needs reordering?", and it looks in your catalogue instead of guessing.

It can search on specifications the same way the Parts screen does, so "supply voltage of at least 3.3 V, in a SOT-23 package" is a question it can actually answer. It reads part details, specifications, stock per location, categories, locations and your low-stock list.

It can only read. Nothing reached this way can create or change a part, edit a specification, or move your stock — whatever the assistant is asked to do.

Creating a key on My Account

My Account → AI access (MCP) is where you create a key, one per assistant you want to connect, and revoke one when you no longer do. Creating a key hands you the finished command to paste into Claude Code; other clients want the same address and key. The key is shown once and cannot be shown again, so copy it there and then — if you lose it, revoke it and make another.

A key reads only the organisation you were in when you created it, and never more than you are allowed to see yourself. The list shows when each key was last used, so you can tell a key something is really using from one you have forgotten about.

Connecting Claude Desktop, without copying a key around

Claude Desktop and claude.ai connect to Sortiment by address alone. Add a custom connector pointing at https://your-server/api/mcp — there is nothing else to fill in. Your browser opens Sortiment, asks whether to allow it, and that is the whole setup. No key to copy, nothing to paste into a configuration file.

The approval screen tells you what an application is asking for and, importantly, where it will be sent back to. Any application can call itself anything, so if that address is not one you recognise, refuse. You choose which organisation it may read, and it is limited to that one from then on.

What it can do does not change: read-only, limited to what you can see yourself. You can withdraw access at any time from My Account → AI access.

Keys are still there for anything without a browser — Claude Code, scripts, the command line. Both work at the same time. One requirement worth knowing: connecting this way needs your server to be reachable over HTTPS, which is how the sign-in can be trusted; a local instance on your own machine is fine as it is.
