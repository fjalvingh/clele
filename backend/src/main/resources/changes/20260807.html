Look up a part after you have added it

Part detail has a new Look up specs button. It searches for the part and offers what it finds for you to confirm, one specification at a time: values you have no entry for yet are ticked, values that disagree with what you already stored are listed but left unticked, and values that already match are not shown at all. Until now specifications could only be filled in when a part was created.

One-off, vintage and house-numbered parts often have nothing to find, and the search says so rather than pretending it went wrong.

Parts that are missing specifications

The dashboard has a new tile counting parts with fewer than five specifications. Clicking it opens the Parts screen with the same filter applied, which is also available as Missing specs under More search options.

Specifications are no longer quietly lost

A lookup sometimes returns a specification your catalogue has no field for. Quick Add now shows those under Other and saves them instead of dropping them — use Rescan from parts on the Spec Fields screen to turn them into proper fields. Editing a part no longer deletes specifications that the form does not have a field for.

Datasheets are saved, not just linked

When a part is added through Quick Add its datasheet is downloaded and kept with the part, so it survives the manufacturer moving or removing the file. If the address turns out to serve a web page instead of a document it is refused rather than stored, and the part is added either way.

Read the specifications straight out of the datasheet

Every stored datasheet on part detail now has a Get specs button beside it. It reads the document and offers what it found — the specifications, and a description of what the part does — for you to confirm the same way as Look up specs: new values ticked, values that disagree with what you stored listed but left unticked. Each value shows the page it was read from, so anything that matters can be checked against the document.

It reads only that document, so it is quick and costs a fraction of a web lookup — and it usually finds more, because a datasheet lists everything the manufacturer publishes. Nothing runs until you press the button, and nothing is changed until you apply it.

Some datasheets cannot be read: an older one whose specification tables are pictures rather than text will yield a description and little else, and a datasheet that is nothing but a scan is refused outright. In both cases it says which it is rather than reporting an empty result.
