Each organisation now brings its own AI key — and pays its own bill

Looking a part up with the AI costs real money — a web search lookup runs to somewhere between five and thirteen cents. Until now every organisation spent that through one key belonging to the installation, so one busy month landed on a bill nobody could split. The key has moved onto the organisation: an Organisation Admin enters it under Admin Actions → AI lookup, and from then on that organisation's lookups are billed to its own Anthropic account. You can also name a model there, or leave it on the default.

The key is stored encrypted and is never shown again — only its last four characters, so you can tell which one is in place. Beside it is Test connection, which spends a fraction of a cent to check that the key still works and the account still has credit.

When there is no AI, the rest of the app carries on

An organisation without a key is not a broken one. Adding a part still searches your own catalogue, the component cache and the web — only the AI sources step aside, and Quick Add says so at the top of the screen instead of failing when you press a button.

It also says which of the two things happened, because they need different fixes and they used to look identical: no key has been entered, or the Anthropic account has run out of credit. Once an account is topped up the lookups come back on their own; there is a Check again button next to the message if you would rather not wait to find out.
