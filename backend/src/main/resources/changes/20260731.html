Barcode labels for parts

Every part can now get its own barcode label. The barcode is a Code 128 code of the form CLE-000123 — the CLE- prefix makes it clearly ours, so it can never be confused with a manufacturer's or distributor's barcode. Scan it on the Barcode Scan page and you land on that exact part immediately, with no searching and no guessing; scanning a Mouser or Digi-Key label keeps working exactly as before.

In the Print label dialog, tick Also print a barcode label. The barcode gets a label of its own (with the code printed underneath, so it stays usable if a scan fails), printed right after the part label — through the print dialog or your daemon, whichever you use. Your choice is remembered, and the default can also be set under My Account → Label printing.

Print labels without the print dialog

Label printing no longer has to go through the browser's print dialog. A small print daemon can now be installed on a Linux machine on your network; it picks up print jobs from Sortiment and sends them straight to a network label printer, so printing a label is one click with no dialog, no printer picking and no margin/scale settings to get wrong. Browser printing still works exactly as before and remains the default.

Set it up under My Account → Label printing: switch printing to Daemon, download the daemon, run its installer on the target machine, then claim it on that page and fill in your printer's IP address. Only daemons on the same network as the browser you're using are offered, and a claimed daemon stays private to your account. There's a Test print button to check the setup.

The daemon reads the label stock from the printer itself, so there is nothing to configure about label size — change the roll and Sortiment picks up the new size automatically, and labels are sized to fit it. It also reports the printer's real status: if a job fails you get the printer's own reason ("cover open", "media empty", and so on) instead of a silent failure. Currently supports Brother QL-series network printers.

The daemon reports its version, and My Account warns you when an installed daemon is older than the version this Sortiment expects, so an out-of-date daemon can't quietly misbehave.
