A weekly stock summary by mail

Once a week you now get a short mail with the state of your stock. For each organisation you belong to it lists the parts in the catalogue, the parts in stock, the items on hand, the stock value, how many parts are below their minimum stock, and the number of stock changes in the last 7 days.

For administrators: sending mail

The server now always reads MAIL_HOST and the other MAIL_* settings from its environment, so mail no longer depends on a local configuration file. To stop the weekly summary, set APP_MAIL_STOCK_SUMMARY_ENABLED=false.
